✈️ About

WorldWide Airlines Tickets Booking is a modern travel website concept created for users who want to explore destinations and search for flights through a clean, simple and responsive interface.

The website includes a flight-search section, popular destinations, company information, customer support and a contact form.

Note: This is currently a front-end project. The flight search interface can be connected to a backend and an authorized flight API to provide real-time flight availability, pricing and booking.

The flight-search interface allows users to enter:

🛬 To	Arrival city
📅 Departure	Departure date
📅 Return	Return date
👨 Adults	Number of adults
🧑 Youths	Number of youths
👶 Children	Number of children
🍼 Infants	Number of infants
💺 Cabin	Cabin class
✈️ Airline	Preferred airline
🎟️ Promo	Optional promo code
